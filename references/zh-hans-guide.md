# 写作指南

## 让主干和关系清楚

多层定语容易把动作推迟到句末。先找“谁做什么”，再把必要说明放到邻近位置。限制对象范围的条件与对象一起保留，例如“材料齐全的申请”中的“材料齐全”决定哪些申请适用。

一句话承载的关系越多，越需要调整。遇到多次主体切换、嵌套条件或连续独立任务时，可拆句、分段或列成步骤。关系紧密的分句用逗号衔接，复杂并列用分号，完整意思用句号结束。拆分后核对条件和否定仍然作用于原来的内容。

主体明确时，自然省略重复的称谓和代词。“打开文件，选择‘导出’”已经能说明操作。职责变化时点名，如“申请人提交材料，财务部审核”。“文件已保存”“款项已到账”等状态提示可以直接使用。

遇到“其、该项、相关单位”等可能指向多个对象的表达，按上下文核实所指，直接写出具体名称。重复名称能帮助读者辨明对象；上下文不足时，将所指列为待确认信息。

保留“已、正在、将、仍、尚未”等表示时间与状态的词。用“因为、因此、如果、之后”等连接词时，依据材料中的实际关系。把“只要”用于充分条件，把“只有……才……”用于必要条件；将并列要求写清为“同时满足”或“满足任一条件”。

## 写得具体、自然

把抽象表达还原为材料已有的动作、对象和结果。“对方案的可行性进行评估”可以写成“评估方案是否可行”；“本次更新全面提升使用体验”若实际指一次上传20个文件，就直接写这个变化。

判断一句话的作用：它是否交代事实、解释原因、明确条件，或帮助读者理解？保留这些内容，将相同作用的重复句合并。开头尽早交代事项，结尾承接尚需完成的行动或判断。

正式程度按场景选择。通知可以简洁郑重，服务邮件可以保留歉意，技术说明可以直接使用专业术语。“请提交”“您可以”“打开文件”都各有适合的场景。

把文言式表达改成符合句意的常用词。例如“申请之附件”可写成“申请的附件”，“此项系必填内容”可写成“此项是必填内容”，“惟材料尚未齐全”可写成“但材料尚未齐全”，“俾利审核”可写成“以便审核”。改写后核对归属、判断、转折和目的关系。

保留自然的节奏和熟悉的表达。“及时反馈”“原路退回”可以简洁准确；“调查正在进行”中的“进行”也有实际含义。句子的价值取决于上下文中的信息与作用。

解释观点时给出依据，比较方案时说明共同维度，澄清误解时再突出区别。背景、例子和总结各自服务于具体的理解需要。

## 用词准确且一致

以读者熟悉的词为首选。普通叙述中的 review、deadline 可按语境写成“审阅、截止时间”；产品名、技术名称和读者熟悉的缩写沿用惯用写法。

同一概念沿用同一名称，首次出现的陌生术语解释到足以理解或操作。例如，面向初学者可写“API（供程序调用的接口）”。解释一个概念需要另一个概念时，先说明基础概念，再讲两者关系。解释“缓存命中”前，可先说明缓存是为便于再次使用而临时保存的数据。

依据地区、行业和产品约定选择术语。信息、数据、资料，文件与档案，程序与代码，保存与存储，各按实际含义使用。引用界面操作时，使用屏幕上真实的标签。

人名、机构名、注册名称、证照字段和直接引文按材料核对。需要补充通行名称时，在首次出现处说明两者关系。

量词按计数对象选择，如“一份申请、三项条件、两次操作”。核对数量指的是材料份数、类别、人数还是发生次数，让数字与对象一一对应。

## 保留条件与证据强度

把限定放在它限定的结论旁边。“退款通常在5个工作日内到账”中的“通常”和“工作日”属于完整信息，概览、标题和正文都应保持一致的含义。

规范性文本中的“应当”常表示义务，“可以”可能表示许可或能力，“不得”表示禁止，“不必”表示无需做。改写前辨明其功能，并保持原有约束程度。

否定句要核对范围。例如“并非所有格式都受支持”说明支持范围有限。遇到含义不明确的原句，先确认范围，再选择清楚的表达。

“目前未发现”“样本中”“与……相关”“预计”等分别说明证据状态、研究范围、关联关系或预测。保留这些信息，并让措辞强度与材料相称。

合并含义重复的不确定表达，如把“或许有可能延迟”写成“可能延迟”。“目前、部分、可能”等分别限定时间、范围和确定程度时，各自保留。

原文缺少期限、接收人或渠道时，可以完成措辞整理，并单独指出影响执行的待补信息。具体值以补充材料为准。

## 专业文本的写法

法律或制度文本写清适用主体、触发条件、义务或许可、例外，以及材料已明确的后果。保留条款编号和定义，交叉引用写出条款编号及其内容。通俗摘要覆盖关键条件，标明正式条款的位置，并说明以正式条款为准。

技术说明先交代目的和使用条件，再说明流程及必要细节。步骤按实际依赖排列，完成状态和错误处理均依据已知行为。代码、命令、标识符、路径、日志、占位符和版本号逐字保留。

科学与医学说明把结论、研究对象、样本范围和不确定性一起交代。数据保留单位、有效数字、误差与统计口径。比喻和例子用于解释已有机制，随后说明其中关键的对应关系和适用范围。

## 标点与排版

正文采用中文标点：词语并列用顿号，分句停顿用逗号，较复杂的并列用分号。横排引号外层用“”，内层用‘’；作品和文件标题按用途使用《》，说明性夹注使用（）。省略号写作“……”，破折号写作“——”。已有发布体例时保持一致。

汉字连续书写。字母、数字与正文之间的间距沿用项目体例；“2026年10月25日”“10 GB”等写法保持一致。代码、公式、网址和标识符内部保留原有符号与空格。

用标题和阅读顺序表达层次，用文字说明重要含义。图表的关键结论有相邻文字解释；表格的表头能说明数值归属；链接文字能独立说明目的地。

## 数字与时间

| 内容 | 核对方法 |
| --- | --- |
| 数量 | 比较和计算的量用清楚的数字；“三五天”等概数保留原意 |
| 数量级 | 改写大数时核算等值，如1200000等于120万 |
| 百分比 | 从10%到15%是增加5个百分点，相对增幅为50% |
| 倍数 | 区分“增加两倍”和“增加到两倍”，核对原值与结果 |
| 区间 | 核对上下限、是否包含边界，以及“至少、至多、超过”等含义 |
| 日期 | 采用含义明确的日期；“03/04/2026”等写法先确认原义 |
| 期限 | 保留起算点、工作日或自然日、截止时间及已有时区信息 |
| 金额 | 核对币种、税费口径、约数与精度 |
| 单位 | 区分MB与Mb、GB与GiB、mg与g，换算后复核 |

来源明确时，可将相对日期写成绝对日期。缺少依据时，保留材料原有的精度。新增的计算结果应能由已有数据直接核验。

## 按阅读任务安排信息

通知先交代事项和影响，再给适用对象、时间及所需行动。操作指南先列前提，再写步骤与已知的完成状态。错误提示说明已确认的问题，并提供有依据的处理办法。

操作存在分支时，把每个条件与对应动作放在同一项中。例如“已注册：直接登录；尚未注册：先注册账号”。分支内需要依次完成的操作再编号，便于读者选定路径后逐步执行。

报告先给结论与关键限定，再展开证据；长篇解释先补齐理解所需的概念，再逐步展开机制。便于查阅的细节放在有明确入口的补充部分。

按读者的实际路径复核：找到适用内容，读懂关键关系，完成操作或作出判断。根据卡住的位置调整信息、用词和结构。
